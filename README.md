# Polynomial Lab — 多項式の根・既約性

Q・F_p 上の一変数多項式について、既約性、既約因数分解、根と重複度を調べる小さな Web アプリです。計算は利用者のブラウザ内で行います。GitHub Pages などの静的ホスティングで公開でき、計算用サーバーは不要です。

## できること

- `x^4-4x^2+2` のような文字列を入力。
- 係数体 Q / F_p の選択。p は素数かを検証。
- 選択した係数体上での厳密な既約性判定と既約因数分解。
- 根の範囲は代数的閉包の全根が既定値。Q では実数のみ・有理数のみ、F_p では F_p 内のみにも絞れます。
- 各根の重複度、および重複度を含めた総数を表示。
- Q の根は厳密値と近似値を表示。根号で表せない場合にも RootOf による厳密表示を使用。
- 有限体の根は、既約因子ごとに定義した有限拡大体で厳密に表示。
- 通常の文字列、整形数式、両方を切り替え。テキスト・LaTeX のコピー。
- キーボード操作、明示的なラベル、計算状態・入力エラーの通知、計算の中止。
- 同じ計算モジュールを使う CLI。

## 数学上の仕様

### 係数体と根の範囲

既約性は常に「係数体」で判定します。例えば Q を選び、根の範囲を代数的閉包にしても、既約性は Q 上での判定です。

### Q の全根

厳密な代数的数として各根を求め、その数値近似を別に表示します。`RootOf(f(x), k)` は、多項式と根番号で一意に指定した厳密な値です。近似値を代入した誤差から既約性を推測する処理は行いません。

### 有限体の全根

F_p 上で `f = c * product(g_i^e_i)` と既約因数分解します。次数 d の既約因子 g には `K = F_p[t]/(g(t))` を用い、a を t の剰余類とします。全根は `a, a^p, ..., a^(p^(d-1))` です。それぞれを g で還元した座標で表示し、元の因子の重複度 e を付けます。

例えば F_2 上の `x^2+x+1` では、`a^2+a+1=0` を満たす a を用いて、根は a と a+1 です。

異なる既約因子に由来する根は、それぞれの拡大体で表示します。共通の分解体への埋め込み、任意の F_(p^m) を指定する探索、異なる因子の根同士の演算は、この版の対象外です。

### 全根の個数

正次数の多項式で「代数的閉包」を選択した計算が完了した場合、重複度の合計が次数に等しいことを検査します。次数は、選択した体で係数を正規化した後の値です。範囲を実数や基礎体に絞った場合、根の総数は次数未満になり得ます。

零多項式では、指定した範囲のすべての元が根です。非零定数は単元であり、既約・可約の二択にまとめません。

## 入力

一変数 x、整数、分数、有限小数、加減乗除、非負整数乗、括弧を使用できます。

例:

```text
x^4-4x^2+2
(x-1)^3*(x+2)
x^3+(1/2)x-1
0.1x^2-1
```

有限小数は正確な有理数として解釈します。割り算の分母には非零の定数を指定してください。任意の Python コード、関数呼び出し、多変数、変数を含む分母は受け付けません。

F_p では、約分後の分母が p で割れる有理係数を拒否します。単に分母を払って別の多項式に変換することはありません。

## 計算量の上限

- 入力長: 3,000 文字。
- 入力解析中の多項式の次数: 50 以下。
- 整数係数の分子・分母: それぞれ 100 桁以下。
- p: 2 以上 2,147,483,647 以下の素数。
- 近似値の有効桁数: 5〜50。
- Web での 1 回の計算: 30 秒。時間切れや中止の場合は計算未完了として扱います。
- 計算環境の初期読み込み: 最大 90 秒。初回はライブラリのダウンロードに時間がかかります。

入力が上限内でも、すべての多項式について 30 秒以内の完了を保証するものではありません。

## ローカルで Web 版を使う

Node.js 18 以上と Python 3 があれば、次を実行できます。npm の依存パッケージのインストールは不要です。

```bash
node scripts/build.mjs
python3 -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000/` を開きます。HTML ファイルの直接オープンではなく、上記の HTTP サーバーを使用してください。

Web 版の利用時には Python のローカルインストールは不要です。上の Python はローカル配信用の簡単な HTTP サーバーとしてだけ使用しています。

## CLI

Python 3.12 を推奨します。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python cli.py 'x^4-4x^2+2' --field Q
.venv/bin/python cli.py 'x^3+x+1' --field Fp --p 2
.venv/bin/python cli.py 'x^5-x-1' --field Q --digits 30 --json
```

オプションの一覧:

```bash
.venv/bin/python cli.py --help
```

CLI は Web と同じ数学的入力制限を使います。実行時間を制限するには、Linux の `timeout 30s` などを前置できます。

## テストとビルド

```bash
.venv/bin/python -m unittest discover -s tests -v
node scripts/build.mjs
```

GitHub Actions でも Python のテストと静的ファイルのビルドを実行してから公開します。

## GitHub Pages に公開する

このプロジェクト専用のリポジトリを作成し、ソースを push します。GitHub 側のリポジトリ設定で、Pages の Source を GitHub Actions に設定してください。`.github/workflows/pages.yml` が main ブランチの push または手動実行で公開します。

GitHub CLI の `gh` が使える場合は、同梱の `scripts/publish-github.sh` でも、アカウントの確認、専用リポジトリの作成、push、Pages の設定を行えます。使用方法はそのスクリプトの `--help` を参照してください。

## データと外部配信

入力した多項式は計算サーバーに送信しません。計算処理は Web Worker 内で行います。初期読み込みでは Pyodide・SymPy と数式表示用の KaTeX を固定バージョンの CDN から取得します。ネットワーク接続と、その CDN へのアクセスが必要です。

ブラウザには表示形式の設定だけを保存します。入力履歴や計算結果を外部サービスへ保存する機能、解析用トラッカー、アカウント登録機能はありません。
